# API Testing: Postman Echo

Проект по автоматизации тестирования HTTP-запросов с использованием сервиса Postman Echo.


## Описание проекта
Цель проекта — отработка навыков отправки POST-запросов и валидации ответов сервера с помощью библиотеки RestAssured и Hamcrest Matchers.

## Стек технологий
- **Язык:** Java 11
- **Тестовый фреймворк:** JUnit 5
- **Библиотеки:**
    - RestAssured (тестирование API)
    - Hamcrest (проверка данных в ответе)
- **Сборщик:** Gradle
- **CI/CD:** GitHub Actions

## Ключевые реализованные задачи
1. **Тестирование POST-запросов:** Реализована отправка данных в теле запроса (body) на эндпоинт `https://postman-echo.com/post`.
2. **Валидация ответов:** Написаны проверки, подтверждающие, что сервер возвращает отправленные данные в неизменном виде.
3. **Логирование:** Настроено логирование запросов и ответов (`.log().all()`) для отладки и анализа взаимодействия с API.
4. **CI/CD:** Настроена автоматическая сборка проекта в GitHub Actions для контроля стабильности тестов.
